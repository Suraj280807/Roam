# 🌍 Roam — AI-Powered Travel Companion

### Transforming Navigation into Interactive Exploration

Roam is an AI-powered travel companion designed to transform ordinary travel into an engaging journey of discovery. It helps travelers explore nearby landmarks, uncover hidden gems, learn about the history and culture of places, collect travel achievements, and preserve their experiences in a digital travel journal.

Instead of simply showing users where to go, Roam helps them understand **why a place matters**.

---

## ✨ Key Features

### 📍 Real-Time Discovery

Discover nearby landmarks, tourist attractions, and hidden gems based on your location and interests.

### 🤖 AI-Powered Travel Guide

Explore historical facts, cultural significance, local stories, and interesting insights about destinations.

### 📸 AI Landmark Recognition

Identify landmarks through camera-based exploration and learn more about the places around you.

### 🗺️ Interactive Exploration

Explore destinations through map-based discovery and contextual location information.

### 🏆 Travel Passport & Stamps

Collect digital travel stamps, track discoveries, and celebrate your exploration achievements.

### 📔 Digital Travel Journal

Build a personalized record of visited places, saved destinations, and memorable experiences.

### 🔔 Smart Travel Notifications

Receive relevant travel information and location-based updates while exploring.

---

## 💡 The Problem We Solve

Traditional travel applications primarily focus on navigation, leaving travelers to switch between multiple platforms to understand the places they visit.

Roam aims to address five key challenges:

- **Lack of context:** Maps show where a place is, but not always why it matters.
- **Fragmented experiences:** Travelers switch between maps, search engines, and travel guides.
- **Hidden gems:** Lesser-known local attractions can be difficult to discover.
- **Passive exploration:** Navigation often ends when the traveler reaches a destination.
- **Lack of rewards:** Traditional navigation offers limited motivation to explore further.

## 🚀 Our Approach

Roam transforms the traditional travel journey into an interactive experience:

**Discover → Explore → Learn → Earn → Remember**

Every destination becomes an opportunity to learn something new, discover something unexpected, and create a lasting memory.

## 🔄 How Roam Works

1. **Detect Location** — Determine the user's surroundings, subject to location permissions.
2. **Discover** — Find nearby attractions, landmarks, and hidden gems.
3. **Understand** — Present contextual information, historical stories, and cultural insights.
4. **Explore** — Interact with destinations and learn more about landmarks.
5. **Earn** — Collect travel stamps and exploration achievements.
6. **Remember** — Preserve discoveries in a personalized travel journal.

## 💻 Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_FOLDER>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to preview the application.

> These commands apply to a typical Vite-based React project. Verify the scripts in `package.json` if your project uses a different setup.

---

## 🔐 Environment Variables

If external APIs are configured, create a `.env` file containing the required environment variables.

Example:

```env
VITE_MAPS_API_KEY=your_maps_api_key
VITE_AI_API_KEY=your_ai_api_key
```

Use the actual variable names expected by your implementation. Never commit real API keys, passwords, or other secrets to GitHub. Secret AI API keys must be kept on a secure backend rather than exposed in browser code.
